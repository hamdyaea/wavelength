# Wavelength Calculator

**Developer:** Hamdy Abou El Anein  
**Contact:** info@daylightlinux.ch  
**License:** See LICENSE.

Convert frequency in megahertz to free-space wavelength in metres using the exact SI speed of light (299,792,458 m/s). Python 3/Tkinter GUI and command-line mode. This is a free-space approximation; propagation in cables and other media differs.

```sh
python3 wavelength.py
python3 wavelength.py --mhz 145.8
python3 -m unittest discover -s tests -v
```

Original implementation: [old branch](https://github.com/hamdyaea/wavelength/tree/old).
